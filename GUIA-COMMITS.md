# Sequência de commits para o GitHub

O professor exige evolução gradual e commits feitos por você. Por isso, o ZIP **não inclui um histórico Git pronto**.

Faça os commits na sua conta, nesta ordem, enquanto monta o repositório:

1. `chore: cria projeto React com Vite`
2. `docs: adiciona paginas originais como referencia`
3. `chore: configura Tailwind e identidade visual`
4. `feat: cria navbar e rodape unico`
5. `feat: cria secoes inicio e sobre`
6. `feat: migra loja como secao da landing`
7. `feat: adiciona filtro e carrinho com estado`
8. `style: ajusta responsividade no celular`
9. `docs: adiciona README com instrucoes e origem`
10. `docs: adiciona link do site publicado no Netlify`

## Publicação no Netlify

- Build command: `npm run build`
- Publish directory: `dist`

Antes de entregar:

```bash
npm install
npm run build
npm run preview
```

Abra o site no celular e em aba anônima.
